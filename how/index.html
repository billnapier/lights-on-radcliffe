How?

What goes into putting together a 1,200+ light synchronized holiday display.

So What Goes Into This Lightshow?

First and foremost, a lot of wires—power cables, ethernet cables, and pixel cables to name a few. For power, I use a lot of landscaping extension cords and a few splitters. I also run a dedicated ethernet network for the light show that has no internet connection (it doesn't need it).

Hardware

  • 2 Ethernet switches: One up on the front porch to run ethernet to everything on the right side of the house, and a second ethernet switch in the garage to split out the data network for the left of the house.
  • 4 AlphaPix Classic Pixel Controllers (from HolidayCoro): These run all the lights except for the big "Mega Tree", which is run by an AlphaPix Flex Controller. There is also a Flex Controller configured to run AC lights (on/off/dim) that I use for the ground lights in front of the garage.
  • 1 Raspberry Pi 4: This used to be a much older Raspberry Pi that I just happened to have lying around, but it was super underpowered and the show audio would glitch sometimes. After upgrading to the Pi 4, I've not had any problems with it at all. This device coordinates the schedule for the show, plays the audio to be broadcast, and decodes the sequences to relay to the pixel controllers.

Software

There are two main pieces of software used in the show (plus Remote Falcon so viewers can pick songs!):

  • xLights: Open-source sequencer software. This allows me to import a music track and the layout for the lights, and tell the lights what to do and when. It is free.
  • Falcon Player (FPP): The distribution that runs on the Raspberry Pi to schedule and run the show. It is also free.

How About the Lights Themselves?

The house outline is done with PVC pipe. The lights are zip-tied onto the PVC pipes, and HolidayCoro sells specific transparent clips that are used to attach them to the house (the clips remain on the house year-round; the PVC pipes are supposed to come down each year, though they didn't one year).

The "Mega Tree" was a HolidayCoro kit, as were all the mini-trees. The Mega Tree is a series of plastic strands attached to a vertical fence rail. The mini-trees come apart and lie flat for storage.

The arches are made from PVC pipe and transparent PEX pipe and use the only LED strips in the show. It boils down to running an LED strip through the PEX, supported by a base made from PVC pipes.
